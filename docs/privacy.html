‹ 밤노트

데이터 사용 안내

밤노트는 이 휴대폰 안에서 일기를 써요. 운영자가 볼 수 있는 정보는 없어요. 앱 안 설정 → 정보 → 데이터 사용 안내와 같은 내용이에요.

캘린더

읽는 것: 일정 제목 · 시간 · 종일 여부. 읽지 않는 것: 참석자 · 메모 · 장소 상세. 거절한 일정은 빼요.

걸음 · 운동 (Health Connect)

읽는 것: 하루 걸음 수, 운동 종류 · 시간. 읽지 않는 것: 심박 · 수면 · 체중 등 다른 건강 기록. 일기 문장과 회고 막대에만 써요.

사진

읽는 것: 찍은 시각 · 장수 · 위치. 사진 내용은 보지 않아요. 메모에 직접 붙인 사진만 줄여서 저장해요.

위치

10분 남짓마다, 움직일 때는 500m쯤마다 대략의 위치를 휴대폰에 남겨 머문 장소를 묶고, 그날의 이동 선을 지도에 그려요. 원본 위치는 보관 기간(기본 30일)이 지나면 지워요(그 뒤엔 머문 곳만 남아요).

밖으로 나가는 것

① 구글 드라이브 백업(준비 중)을 켜면 내 구글 계정의 앱 전용 폴더(드라이브 목록에 안 보임)에 일기 · 기분 · 메모 · 줄인 사진 · 설정을 담은 백업이 하루 한 번 올라가요(최근 3개). 운영자는 볼 수 없어요. 설정에서 끌 수 있어요.

② 이동 기록 지도를 열면 그 지역의 지도 그림을 오픈스트리트맵 서버에서 받아요. 서버는 접속 IP 와 어느 지역 지도를 받았는지 알 수 있어요. 내 위치 기록 자체는 보내지 않아요.

③ 새 버전을 확인하고 받으려고 GitHub 에 접속해요.

④ 설정 → 백업 파일 만들기를 누르면 일기 · 기분 · 메모 · 사진 · 설정을 담은 파일을 내가 고른 곳에 저장해요. 파일은 암호화되지 않아요.

온디바이스 AI (Gemini Nano)

온디바이스 AI가 준비된 휴대폰에서 초안을 열 때만 그날의 기록 목록을 휴대폰 안의 Gemini Nano(Android AICore)에 넘겨요. 글은 휴대폰 안에서 만들어지고, 글을 만들려고 서버로 보내지 않아요. 설정에서 끌 수 있어요.

이 기능은 Google ML Kit 라이브러리를 쓰기 때문에 Google 의 ML Kit 약관이 적용돼요.

종교 · 기도

고른 종교와 기도 · 돌아보기 글은 휴대폰 안에서만 만들어요. 종교 설정은 밖으로 보내지 않아요.

동 이름 · 지도 출처

머문 곳의 동 이름은 앱에 들어 있는 행정동 경계로 휴대폰 안에서 찾아요. 좌표를 밖으로 보내지 않아요.

행정동 경계: 통계청 통계지리정보서비스(SGIS, sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다. 앱에 넣으려고 경계를 단순화했어요.

지도: © OpenStreetMap 기여자

그 밖에

광고 · 크래시 수집 도구를 쓰지 않아요. 진단 기록은 휴대폰에만 남고, 직접 공유할 때만 나가요.

혼자 쓰려고 만든 앱이에요. 문의는 GitHub 이슈로 남겨 주세요.
